# Contributions

Please discuss substantial changes with the maintainers before submitting them.

Webdock offers its original code under AGPL-3.0-only and may offer alternative written commercial licenses. Read [COMMERCIAL-LICENSING.md](COMMERCIAL-LICENSING.md) before contributing.

You retain your copyright. Before maintainers accept an outside contribution into a portion intended for commercial relicensing, they need a separate written contributor agreement providing sufficient sublicensing rights. A pull request, an AGPL grant or a sign-off alone is not treated as that agreement. Include the provenance and existing license of any third-party code; do not submit code you lack permission to contribute.

Never include credentials, customer data or production database exports in a contribution. Use the repository's owned disposable fixtures for verification.
