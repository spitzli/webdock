Webdock brings your websites, applications and workspace services into one console. Your account controls which workspaces and resources you can access. Website content stays in the website's own CMS instance.

## Your Webdock addresses

| Address | Purpose |
| --- | --- |
| [console.webdock.dev](https://console.webdock.dev) | Workspace and resource management |
| [auth.webdock.dev](https://auth.webdock.dev) | Sign-in, account security and OAuth consent |
| [webdock.dev](https://webdock.dev) | Product website |

<Note>
Console is the browser application. Existing integrations keep their registered protocol addresses, including the Studio MCP endpoint. See [authentication](/developers/authentication) before changing an integration URL.
</Note>

## Availability

Services depend on your workspace's enabled products, permissions and capacity. An API reference describes a contract; it does not mean a service is enabled for every workspace. Check the relevant product guide and the state shown in Console.
