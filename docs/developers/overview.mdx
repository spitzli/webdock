Webdock exposes different interfaces for message sending, registry automation and hosting operations. Their credentials and permissions are not interchangeable.

| Task | Interface | Authorization |
| --- | --- | --- |
| Send transactional email | Mail REST API | Workspace-scoped Webdock Mail API key |
| Read or maintain customer and project inventory | Registry REST API or MCP | Registered OAuth client and registry scopes |
| Inspect or manage hosting resources | Hosting MCP | Registered OAuth client and hosting scopes |
| Integrate a website CMS | Website SSO and protected bridges | Server-side website integration |
| Work on Webdock itself | Repository and internal HTTP client | Isolated local development configuration |

## Integration rules

Treat platform IDs as decimal strings. Keep credentials on the server and request only the permissions needed. Inspect operation outcomes before retrying mutations. Use the documented public protocol; the Console's internal browser API is not a substitute for an authorized integration.
